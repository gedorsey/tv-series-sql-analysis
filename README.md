# TV Show Ratings Analysis — SQL Project

## Overview
This project explores an IMDb TV shows dataset from Kaggle using SQL to uncover trends 
in ratings, genres, runtimes, and audience engagement.

## Dataset
Source: IMDb TV Shows Dataset (Kaggle)  
Fields include: title, genre, rating, votes, year, episode duration

## Questions Explored
1. What are the highest-rated TV shows of all time?
2. Which genres consistently score the best ratings?
3. Which shows have the most audience engagement (votes)?
4. How many shows exist per genre?
5. Which shows are highly rated AND widely watched?
6. Which shows have the longest runtimes?
7. Does a longer runtime correlate with a better rating?
8. Which genres dominate among top-rated shows?
9. What are the most underrated hidden gem shows?

## Key Findings
- Breaking Bad and Game of Thrones top both ratings and votes among mainstream shows
- Shows running 3–5 years have the highest average rating (7.44)
- Shows running 10+ years have the lowest average rating (7.20)
- Crime, Drama, Thriller have the highest avg rating (8.55) among top genres
- Bluey is rated 9.7 but has only 3,005 votes — a major hidden gem
